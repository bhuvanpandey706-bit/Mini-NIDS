Reporting a Vulnerability

If you discover a potential security vulnerability in Mini-NIDS, please report it responsibly.

Where to report: Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository owner privately through GitHub.

What to include: Describe the vulnerability, steps to reproduce it, potential impact, and any relevant logs or screenshots. Do not include real users' sensitive data.

Response time: I will aim to acknowledge reports within 7 days. This is a target, not a guaranteed response time.

Resolution: I will review the report, assess its impact, and communicate whether a fix or other action is planned.

Please do not publicly disclose an unpatched vulnerability before coordinating with the project owner.

Scope and Disclaimer

Mini-NIDS is an educational network intrusion detection prototype that analyzes PCAP files. It is not a replacement for an enterprise security monitoring system. Test it only with traffic and systems you own or are authorized to analyze.
